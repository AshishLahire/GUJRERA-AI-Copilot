# Voice recording sheet (30 clips)

Read each line aloud once, naturally, as you would ask a helpline. Record on a phone (a WhatsApp voice note is fine) or a laptop, in a normal room. Save each recording with its ID as the file name, e.g. `gu_01.m4a`, in `data/eval/gujrera_voice/clips/`, then run `python scripts/eval_gujrera_voice.py`.

Different speakers for different languages are better than one person reading everything. Small slips are fine: the evaluation compares against the text below, so read it as written.
